## 0. Эхлэхийн өмнө (нэг удаа)

1. https://github.com/signup дээр GitHub бүртгэл үүсгэнэ.
2. Төслийн эзэмшигчид өөрийн GitHub нэрээ хэлнэ. Тэр таныг **Settings → Collaborators → Add people** хэсгээс нэмнэ.
3. Имэйлээр ирсэн урилгыг **Accept invitation** дарж зөвшөөрнө.
4. https://github.com/cerebrumanthropic/kripto-7hon хуудасны баруун дээд талын **Watch → Custom → Pull requests** сонголтыг чагтална. Ингэснээр шинэ ноорог ирэхэд имэйл хүлээж авна.

## 2. Ноорог бөглөх

### 2.1 PR-ийг нээх
1. Имэйлээр ирсэн холбоос дээр дарна. Эсвэл репозиторийн **Pull requests** таб руу ороод «Тайлан … — ноорог» гэснийг нээнэ.
2. PR-ийн тайлбар хэсэгт QA шалгах жагсаалт байгаа. Үүнийг 3-р алхамд бөглөнө.

### 2.2 Засах файлаа олох
1. PR-ийн дээд хэсгийн **Files changed** таб руу орно.
2. `content/reports/2026-W44.md` файлыг олно. `.json` файлд гар хүрэхгүй: тэнд автоматаар татсан тоо хадгалагддаг.
3. Тухайн файлын баруун дээд буланд байрлах **⋯** товч дээр дарж **Edit file**-ийг сонгоно.

### 2.3 Талбаруудыг бөглөх
Файлын дээд хэсэг `---` хоёр зураасын хооронд байрладаг. Доорх талбаруудыг бөглөнө.

| Талбар | Юу бичих вэ | Жишээ |
|---|---|---|
| `headline` | Гол гарчиг: **тоо + чиглэл + шалтгаан**, ≤120 тэмдэгт | `"ETF-ээс 1.5 тэрбум ам.доллар гарч, BTC 5 хувиар унав"` |
| `summary` | 1–2 өгүүлбэр. Нүүр хуудас болон нийгмийн сүлжээнд хуваалцах үед харагдана | `"Биткойн 7 хоногт …"` |
| `takeaways` | **Яг 3** гол санаа, тус бүр тоотой | `- "Нийт зах зээл 3.2 хувиар буурч …"` |
| `etf.btc_net_flow_usd` | BTC спот ETF-ийн 7 хоногийн цэвэр урсгал (ам.доллар). Гарсан бол хасах тэмдэгтэй, **таслалгүй** бичнэ | `-1470000000` |
| `etf.eth_net_flow_usd` | ETH-ийн мөн адил | `212000000` |
| `etf.source_name`, `source_url` | Тоог авсан эх сурвалж. Урсгал оруулсан бол заавал бөглөнө | `"Farside Investors"`, `"https://farside.co.uk"` |
| `coinshares` | CoinShares-ийн 7 хоногийн ETP урсгал ба холбоос (заавал биш) | |
| `mongolbank_usd_mnt` | Монголбанкны албан ханш (заавал биш) | `3412.5` |
| `news_picks` | 3–5 онцлох мэдээний **URL**. Доод хэсгийн «Сонгох боломжтой мэдээ» жагсаалтаас хуулна | `- "https://…"` |
| `mongolia` | Монголын мэдээ: богино тайлбар ба холбоос | доор харна уу |
| `regulation` | Зохицуулалтын мэдээ | доор харна уу |
| `calendar` | Ирэх 7 хоногийн үйл явдал (огноо `ОООО-СС-ӨӨ`) | доор харна уу |
| `author` | Таны нэр | `"Б. Болд"` |
| `status` | Бэлэн болсон үед `published` болгоно | `published` |

Олон мөртэй талбарыг дараах хэлбэрээр бичнэ. Зайг (2 эсвэл 4 хоосон зай) яг ижил байлгах шаардлагатай:

```yaml
mongolia:
  - text: "СЗХ шинэ ВХҮҮ-д тусгай зөвшөөрөл олголоо."
    url: "https://www.frc.mn/..."
calendar:
  - date: "2026-10-28"
    event: "АНУ-ын FOMC хүүгийн шийдвэр"
  - date: "2026-10-30"
    event: "Евро бүсийн инфляци"
```

**Бичихдээ анхаарах дүрэм:**
- Текстийг **давхар хашилт** `"…"` дотор бичнэ.
- Тоо бичихдээ таслал хэрэглэхгүй. `1,470,000,000` биш, `1470000000` гэж бичнэ.
- Холбоос заавал `https://`-ээр эхэлнэ.
- `---` мөрүүдийг устгахгүй.
- «Хөрөнгө оруулалтын зөвлөгөө» болох «худалдаж ав», «зар» гэх мэт үг хэллэг хэрэглэхгүй.

**Автомат санал болгох өгүүлбэр:** Файлын доод хэсэгт `<!-- auto-suggestions …` гэсэн хэсэгт санал болгох өгүүлбэрүүд байдаг. Тэдгээрийг хуулж headline болон takeaways-д ашиглаж болно. Энэ хэсэг сайтад харагдахгүй.

**Чөлөөт тайлбар (заавал биш):** Хоёр дахь `---` мөрийн доор энгийн догол мөр бичиж болно. Гарчиг бичихдээ мөрийн эхэнд `### `, жагсаалт бичихдээ `- ` тавина.

### 2.4 Хадгалах (commit)
1. Хуудасны баруун дээд хэсгийн ногоон **Commit changes…** товчийг дарна.
2. **Commit directly to the `report/2026-W44` branch** сонгогдсон байгааг шалгана.
3. **Commit changes** дарна.

## 3. Урьдчилан харах ба шалгах

1. Commit хийснээс ≈3 минутын дараа PR дээр «🔍 **Урьдчилан харах:** https://vaspfrcweekly--….expo.app/tailan/2026-W44» гэсэн comment гарч ирнэ. Дараагийн commit бүрт энэ холбоос шинэчлэгдэнэ.
2. Тэр холбоосыг нээж дараахыг шалгана:
   - Инфографик, «PNG татах» товч
   - Товч мэдээ, тоонууд
   - «НООРОГ» гэсэн тэмдэг. Энэ нь зөвхөн урьдчилан харахад гардаг, нийтэлсэн тайланд байхгүй.
3. PR-ийн доод хэсэгт **ногоон ✓** байна уу гэдгийг шалгана. **Улаан ✗** байвал **Details** дээр дарна. Алдааны мессеж монголоор гарна, жишээ нь «takeaways яг 3 байх ёстой». Засаад дахин commit хийнэ.
4. PR-ийн тайлбар дахь QA жагсаалтын нүд бүрийг шалгаад чагтална:
   - Тоог 2 эх сурвалжаар тулгах: CoinGecko ↔ CoinMarketCap, зөрүү ±1%-аас ихгүй байх
   - ▲▼ тэмдэг, нэгж (тэрбум/их наяд), огноо зөв эсэх
   - Үг үсгийн алдаа

> ⚠️ Анхны ноорог ирэх үед CI болон урьдчилан харах хуудас автоматаар **ажиллахгүй** (GitHub-ийн хязгаарлалт). Та анхны засвараа commit хийснээр л ажиллаж эхэлнэ.

## 4. Нийтлэх (Даваа 12:00)

1. `status: draft`-ийг `status: published` болгож commit хийнэ (2.4-ийн дагуу).
2. Шалгалт ногоон ✓ болсны дараа PR-ийн доод хэсэгт **Merge pull request** → **Confirm merge** дарна.
3. ≈3 минутын дараа тайлан https://vaspfrcweekly.expo.app/tailan дээр гарна. Нүүр хуудасны «Сүүлийн 7 хоногийн тайлан» хэсэг ч шинэчлэгдэнэ.

## 5. Нийгмийн сүлжээнд хуваалцах

Тайлангийн хуудсанд (`/tailan/2026-W44`) дараах товчнууд байна:
- **PNG татах**: 1080×1350 хэмжээтэй инфографик татна (Instagram, Facebook-д тохиромжтой). «Цайвар» эсвэл «Бараан» хувилбарыг дээр нь сонгоно.
- **Текст хуулах**: Facebook эсвэл Telegram-д шууд наах боломжтой цэвэр текст хуулна. Тайлангийн холбоос дотор нь орсон байна.
- **Хэвлэх / PDF**: хөтчийн хэвлэх цонх нээгдэнэ. «Save as PDF»-ийг сонгоно.

## 6. Залруулга (нийтэлсний дараа алдаа олдвол)

1. Репозиторийн **Code** таб → `content` → `reports` → `2026-W44.md` руу орно.
2. ✏️ (Edit) дээр дарна.
3. Алдаатай текстийг засна. Мөн `corrections` талбарт тэмдэглэл нэмнэ:
   ```yaml
   corrections:
     - date: "2026-10-27"
       text: "BTC-ийн 7 хоногийн өөрчлөлтийг −4.2%-иас −4.0% болгож засав."
   ```
4. **Commit changes** → **Commit directly to the `main` branch** → **Commit changes** дарна.
5. ≈3 минутын дараа сайт шинэчлэгдэнэ. Хуудасны «Залруулга» хэсэгт таны тэмдэглэл харагдана.

> Тайлангийн текстийг тэмдэглэлгүйгээр чимээгүй өөрчилж болохгүй. Залруулга бүрийг `corrections`-д бичнэ (Арга зүй хуудасны залруулгын бодлого).

## 7. Бүрэн автомат горим (заавал биш)

Редактор байхгүй долоо хоногт тайлан автоматаар нийтлэгдэх боломжтой. Ингэхийн тулд репозиторийн **Settings → Secrets and variables → Actions → Variables** хэсэгт `AUTO_PUBLISH`-ийн утгыг `true` болгоно.

Энэ горимд гарчиг ба гол санааг автомат өгүүлбэрээс авна. ETF урсгал, Монгол хэсэг, хуанли хоосон үлдэнэ. Буцааж `false` болгомогц PR горим сэргэнэ.
